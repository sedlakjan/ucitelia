# Dnes učíš ty

Jednoduchá statická frontendová aplikácia pripravená pre GitHub Pages.

## Súbory

- `index.html` – vstupná stránka
- `styles.css` – celý vzhľad
- `app.js` – logika 8-minútovej simulácie
- `og.png` a `favicon.svg` – obrázky stránky

Projekt nepotrebuje Node.js, `npm install` ani build. Na lokálne otvorenie stačí
spustiť ľubovoľný jednoduchý webserver alebo nahrať súbory na GitHub Pages.

## GitHub Pages

1. Nahraj obsah priečinka do koreňa GitHub repozitára.
2. V repozitári otvor `Settings` → `Pages`.
3. V časti `Build and deployment` zvoľ `Deploy from a branch`.
4. Vyber vetvu `main`, priečinok `/(root)` a potvrď `Save`.

Rýchly testovací režim je dostupný pridaním `?demo=1` na koniec adresy.
